# Indian Art Exploration

Two interactive experiences of Indian art history:

- **/explore** — Kāla, an interactive timeline of Indian art, from the rock shelters of Bhimbetka to living folk traditions.
- **/map** — Sangraha, an interactive atlas of India's art history across thirty-two sites.

This is an assignment for the course "indian art form".

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:5173/explore or http://localhost:5173/map.

## Hosting (Netlify)

Import this repo in Netlify. Build settings and redirects live in `netlify.toml` (`npm run build`, publish `dist`).
